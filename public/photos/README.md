# Eddy photos

Put one photo per level in this folder (`public/photos/`), named by level:

| File | Tile |
| --- | --- |
| `eddy-1.jpg` | Eddy Lv 1 (the starting tile) |
| `eddy-2.jpg` ... `eddy-10.jpg` | Eddy Lv 2 to 10 |
| `eddy-11.jpg` | Eddy Li (MIT), the final tile |

`.png` and `.webp` work too. Square photos look best, since tiles crop to a square from the center. Any level without a photo keeps its colored placeholder.
